CHINUUU v2.0.1 UPDATE PATCH
===========================

This archive is an overlay update for an existing Chinuuu v2.0.0 source tree.

1. Close every running Chinuuu CLI/GUI process.
2. Back up the complete project folder.
3. Extract all archive contents over the existing project folder.
4. Preserve your existing config.toml, data/, workspace/ and .venv/.
5. In PowerShell:

   cd D:\Projects\Chinuuu
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip setuptools wheel
   python -m pip install -e ".[dev,windows,documents,voice,wakeword,installer]"
   python -m pytest -q
   if ($LASTEXITCODE -ne 0) { throw "Tests failed. Do not launch Chinuuu." }
   python gui_entry.py

GUI keyboard controls:
- Enter sends the current message.
- Shift+Enter inserts a newline.
- Ctrl+Enter also sends.
- While Chinuuu is processing, the input is preserved and cannot be accidentally cleared.

The package update does not include or replace user data, private config,
Ollama model files, the virtual environment or the workspace.

See RELEASE_NOTES_v2.0.1.txt and README.md for details.
