CHINUUU v4.0.0 UPDATE PATCH

Upgrade target: Chinuuu v3.0.0

1. Exit Chinuuu CLI and GUI completely.
2. Back up the project folder or at minimum data/chinuuu.sqlite3 and config.toml.
3. Extract this ZIP into the existing project root (for example D:\Projects\Chinuuu), preserving folder paths and allowing source files to be replaced.
4. Do NOT delete or replace config.toml, data/, workspace/, .venv/, or locally installed Ollama models.
5. In PowerShell:

   cd D:\Projects\Chinuuu
   .\.venv\Scripts\Activate.ps1
   python -m pip install -e ".[dev,windows,documents,voice,wakeword,installer]"
   python -m compileall -q chinuuu tests
   python -m pytest -q

6. Launch only if tests pass:

   python gui_entry.py

New commands:
- /health  Read-only SQLite, workspace, Ollama/model and tool-registry diagnostics.
- /context Show message, approved-memory, pending-suggestion and summary coverage.

Migration is additive. The new conversation_summaries table is created automatically. Existing chat messages are retained. Summarization never deletes source messages. Interrupted agent runs older than ten minutes are marked interrupted and are never replayed automatically.

The release build test result was obtained in the build environment. Run the commands above on the target Windows PC; hardware, driver and Tkinter acceptance remains device-specific.
