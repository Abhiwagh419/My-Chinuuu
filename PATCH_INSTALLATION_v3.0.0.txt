CHINUUU v3.0.0 UPDATE PATCH

Target: existing Chinuuu v2.0.2 source installation.

1. Close Chinuuu GUI and CLI.
2. Back up D:\Projects\Chinuuu (or your actual project directory).
3. Extract this patch into the existing project root, preserving folder structure and allowing source files to be replaced.
4. Do not replace config.toml, data/, workspace/, .venv/ or models/.
5. Open PowerShell in the project root and run:

   .\.venv\Scripts\Activate.ps1
   python -m pip install -e ".[dev,windows,documents,voice,wakeword,installer]"
   python -m compileall -q chinuuu tests
   python -m pytest -q

6. If tests pass, launch:

   python gui_entry.py

7. Click Control center. Verify Tasks, Memory review and Agent activity tabs.

The patch does not include or overwrite personal database contents, user configuration, workspace files, virtual environment, or local model weights.
Rollback: close Chinuuu and restore the backup project directory.
