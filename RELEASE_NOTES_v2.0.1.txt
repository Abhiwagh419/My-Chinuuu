CHINUUU v2.0.1 — DESKTOP INPUT UPDATE
====================================

This maintenance release improves the GUI composer workflow.

- Enter and keypad Enter send a message.
- A visible shortcut hint appears beneath the composer.
- Shift+Enter inserts a newline for multi-line prompts.
- Ctrl+Enter remains supported as a send shortcut.
- Empty messages are ignored.
- While an assistant request is running, Enter does not clear or discard text.
- Added regression tests for these cases.

Automated validation in the build environment: 226 passed.
The user's prior Windows v2.0.0 run was 217 passed, 4 skipped; the skips
were symbolic-link tests because symlink creation was unavailable. Rerun the
suite after installing this update. Hardware, GUI rendering and optional
model acceptance still require validation on the target Windows machine.
